제1조
목적
중립 ▼
내용 요약
분산에너지 특화지역 내 전력 직접거래 계약 목적 명시. SKA(구매자)가 SKMU(집단에너지 구역전기사업자)로부터 전력을 구매함.
버전 변화
변경없음 V1·V2·최종 동일
유불리
중립. 계약의 법적 근거 조항이므로 실질적 영향 없음.
제2조
정의
중립 ▼
내용 요약
HH(Henry Hub), 두바이유, 환율 등 연료비 연동 산식에 쓰이는 핵심 지표 정의. 탄소배출권, SMP 등도 정의.
버전 변화
추가 V2에서 탄소배출권요금 관련 정의 추가, 최종본에서 갱신 관련 정의 추가
유불리
중립이나 HH·두바이유 기준월 정의가 실제 요금 산정에 직접 영향 — 상세 정의 재확인 필요.
제5조
계약 기간
주의 ▼
내용 요약
수급개시일부터 2031년까지 5년 계약. 최종본에서 자동 갱신 조항 추가.
버전 변화
추가 최종본에서 갱신 조항 신설 — 갱신 조건·협의 시점·거절 방법 명시
유불리
갱신 조항은 양날의 검. SKA가 연장을 원하면 유리, 해지 원하면 갱신 조건 충족 여부 확인 필요. 갱신 시 새 요금 조건 재협상 기회 있음.
확인 필요
갱신 거절 통보 기한(통상 만료 6개월~1년 전)이 명시되어 있는지 확인 요.
제8조
기본요금
중립 ▼
내용 요약
월 기본요금 8,190원/kW. 수전설비 용량 기준으로 매월 고정 부과.
버전 변화
변경없음 V1·V2·최종 8,190원/kW 동일
유불리
3개 버전 변동 없어 안정적. 생산량 상관없이 매월 고정 지출이므로 가동률 하락 시 부담 증가.
비고
한전 고압A 기본요금 수준 대비 비교 필요. 가동률 낮을수록 기본요금 비중 증가.
제9조
연료비요금 (핵심)
불리 요소 포함 ▼
내용 요약
HH·두바이유·환율 연동 변동 단가. 연료비 급등 시 SKA 부담 무제한 증가.
산식
// 연료비요금 (원/kWh) 연료비요금 = α × HH + β × 두바이유 + γ × 환율 보정계수 // α, β, γ 는 계약서 별표 참조
버전 변화
삭제 V1에 있던 ZCC(Zero Cost Collar) 상한 보호 구조 → V2에서 완전 삭제 → 최종본도 없음
유불리
SKA 매우 불리. 연료비 급등 시 SKA는 무한 노출. HH $6 시나리오에서 전기요금 약 20~30% 추가 급등 추정.
대응 방안
① SKMU에 Cap 재협상 요구 ② 자체적으로 HH 관련 금융 헷지 검토 (HH 선물/스왑)
제10조
탄소배출권요금 (신설)
주의 ▼
내용 요약
ETS 이행 확정 전 잠정 1원/kWh 부과, 이행 확정 후 실비 사후정산. V1에는 없던 독립 항목.
버전 변화
신설 V1=없음 → V2=잠정 1원/kWh → 최종=독립 항목으로 분리, 사후정산 명시
유불리
탄소배출권 가격 상승 시 SKA 추가 부담. 실비정산 방식이라 상한 없음. 국내 탄소배출권 가격 모니터링 필요.
확인 필요
사후정산 주기, 정산 기준가격 산정 방법, 상한 여부 계약서 원문 재확인.
제11조
가산요금
소폭 불리 ▼
내용 요약
SKMU의 사업 운영·투자 비용 보전 명목으로 사용량 단위로 부과하는 가산요금.
버전 변화
변경 V1=18원/kWh → V2·최종=19원/kWh (1원 인상)
유불리
연간 수전량 기준 약 수십억원 수준의 추가 비용. 5년 계약 전체로는 상당한 규모.
제12조
기간할인 (A원)
미확정 — 최중요 변수 ▼
내용 요약
5년 장기계약에 대한 대가로 SKA가 받는 할인. 금액(A원/kWh)이 계약 경제성의 핵심.
버전 변화
미확정 현재까지 A원 수준이 명확히 확인되지 않음
유불리
A원 < 25원/kWh → 한전 대비 불리 또는 동등
A원 ≥ 25원/kWh → 한전 대비 유리 (HH $4 기준)
즉시 필요
계약서 별표에서 A원 수치 확인 후 손익분기 시뮬레이션 실행 필요.
제13조
임시적용기간 요금
SKA 유리 ▼
내용 요약
수급개시일 ~ 2026.12.31까지 한전 요금제 연동 임시 단가 적용. 연료비 연동 산식이 안정화되기 전 과도기 보호 장치.
버전 변화
신설 V1=없음 → V2·최종=신설
유불리
SKA 유리. 한전 요금 기준이므로 초기 구간에서 예측 가능한 비용 관리 가능. 2026년 말까지는 연료비 급등 영향 제한.
제14조
중도해지 위약금
주요 리스크 ▼
내용 요약
수급개시 후 SKA가 계약을 중도 해지하는 경우 위약금 부과. 기본요금 합계(해지 시점 기준 1년치 이상) 수준.
버전 변화
부분변경 V2에서 임시적용기간(~26.12.31) 중 해지 시 위약금 면제 조항 추가. 이 외 패널티 조항 자체는 V1·V2·최종 모두 존재함.
유불리
패널티는 사라지지 않음. 임시적용기간 면제는 소폭 완화. 셧다운·중동 이전 시 위약금 부담 여전히 존재.
중요
이행보증보험으로 대체 가능 여부 확인. 상세 내용은 탭③ [중도해지 패널티] 참조.
제45조의6
최소사용량 미달요금
SKA 불리 ▼
내용 요약
계약된 최소 전력 사용량에 미달할 경우 SMP(계통한계가격) 기준으로 페널티 부과.
버전 변화
신설 V1=미확인 → V2·최종에서 신설
유불리
SKA 불리. 생산량 감소·설비 고장·수요 감소 시 패널티 추가 발생. SMP는 시장가격으로 변동성 있음.
즉시 필요
① 최소사용량 수준 확인 ② 생산량 감소 시나리오별 패널티 규모 시뮬레이션 ③ 중도해지 패널티와 중복 여부 검토
제45조의7
부족전력요금
SKMU 공급부족 시 SKA 부담 ▼
내용 요약
SKMU가 계약 물량을 공급하지 못하면 SKA가 한전 보완공급을 받게 되고, 그 비용을 SKA가 우선 부담하는 구조.
버전 변화
신설 V2·최종에서 신설
유불리
SKA 입장에서 불합리. SKMU의 귀책인데 SKA가 추가 비용 부담. SKMU에 구상권 행사 또는 SLA(서비스 수준 협약) 연계 필요.
확인 필요
SKMU 귀책 시 SKA의 보전청구 조항이 명시되어 있는지 원문 확인.

분쟁 발생 시 협의 → 조정 → 소송 순서. 관할 법원 및 준거법 명시.
버전 변화
변경없음 V1·V2·최종 동일
유불리

제60조~
기타 일반 조항 (불가항력·양도·비밀유지 등)
중립 ▼
내용 요약
불가항력(천재지변·전쟁 등), 양도 금지, 비밀유지 의무, 계약 변경 절차 등 표준 조항.
버전 변화

유불리
불가항력 범위가 어디까지 인정되는지 확인 필요. 팬데믹·전쟁·에너지위기 포함 여부.
결론 먼저: 패널티 조항은 사라지지 않았습니다 V1(3/12), V2(3/23), 최종본(5/19) 모두 중도해지 위약금이 존재합니다. 다만 V2에서 임시적용기간(~2026.12.31) 중 해지 시 위약금 면제 조항이 추가되었을 뿐, 핵심 패널티 구조는 그대로입니다.
📌 관련 조항 구조 — 제11조·제13조·제14조 흐름
①
제11조 — 계약 유효 기간 중 정상 운영 상태

SKA가 계약대로 SKMU에서 전력을 구매하는 정상 상태. 패널티 없음.

②
제13조 — SKA가 중도 해지 의사 통보

중도해지 조건 해당 여부 판단. 임시적용기간(~26.12.31) 내 통보 시 면제 가능성 있음.

③
제14조 — 위약금 산정

해지 시점의 잔여 기간에 해당하는 기본요금 합계 (최소 1년치 이상) 수준의 위약금 부과. 이행보증보험으로 대체 가능 여부 확인 필요.

💰 위약금 산정 구조
// 제14조 위약금 (추정 산식) 위약금 = 기본요금(8,190원/kW) × 수전용량(kW) × 잔여 개월수 // 예시: 수전용량 10,000kW, 잔여 24개월 위약금 ≈ 8,190 × 10,000 × 24 = 약 19.7억원 // 이행보증보험 대체 시 실제 현금 지출 방식 다를 수 있음
주의 위 금액은 추정치입니다. 실제 계약서 제14조 원문의 정확한 산정식과 수전용량을 확인하여 정확한 위약금 규모를 계산하시기 바랍니다.

불가항력
계약서 불가항력 조항이 셧다운·해외 이전에 적용되는지 여부 법무팀 검토 필요. 통상 경영 판단에 의한 이전은 불가항력 불인정.
조기 협의
중동 이전 검토 단계부터 SKMU와 계약 변경 또는 조기 종료 협의 개시 권장. 통보 후보다 사전 협의가 위약금 협상에 유리.
보험 대체
이행보증보험 전환 가능 여부 확인 — 현금 부담을 보험료로 대체하면 재무적 충격 완화 가능.
🔥 연료비 급등 시 SKA 노출 현황
ZCC 삭제로 SKA는 연료비 급등에 무방비 상태 V1에 있던 Zero Cost Collar(연료비 상한 보호) 구조가 V2 이후 삭제되었습니다. 현재 계약에는 연료비 급등 시 SKA를 보호하는 계약상 Cap이 존재하지 않습니다.

📋 SKA가 취할 수 있는 Hedge 방법
  • 1
    SKMU에 Cap 재협상 요구 (최우선) 계약서에 연료비 상한 조항 재도입. HH가 일정 수준(예: $5.5) 초과 시 초과분을 SKMU/SKA 분담 또는 Cap 적용. 현재 계약 이행 전이라면 재협상 기회 있음.
  • 2
    HH 선물/스왑 활용 CME HH 선물 또는 OTC 스왑을 통해 가스 가격 상한 고정. 비용 발생하나 급등 리스크 차단. 트레이딩팀과 협의 필요. 보통 1~2년 단위 롤링 헷지.
  • 3
    LPG/LNG 구매 조건과 연동 SKA가 이미 HH 연동 LNG 구매 포지션을 보유하고 있다면, 전력요금의 HH 연동 효과와 상쇄되는 부분 분석. 자연 헷지(Natural Hedge) 비중 확인.
  • 4
    두바이유 노출 관리 연료비 산식에 두바이유 계수(β)가 있다면 원유 가격 급등 시도 추가 부담. Brent/Dubai 스왑 또는 콜 옵션 매수 검토.
